# HeroEditorial Pattern

Asymmetric 50/50 split hero designed to pair concrete thesis copy on the left with a live interactive artifact on the right.

## When to Use

- Product documentation entry points and design-system landing pages.
- Technical releases where visitors benefit from inspecting a live widget, terminal workflow, or file structure immediately above the fold.

## Typography & Hierarchy

- **Headline**: `--font-display` (`--text-display-lg`, weight `600`, `--tracking-tighter`).
- **Eyebrow**: `--font-mono` uppercase `--text-xs` with `--tracking-caps` in `--accent-primary`.
- **Summary**: constrained to `54ch` left-aligned prose.

## Mistakes to Avoid

- Do not replace the right-hand artifact with a decorative purple/cyan gradient blob.
- Do not center-align the copy and stack three identical icon cards underneath.
- Do not pad the headline or summary with generic marketing clichés.
